# 🎬 ScarlyPlayer

Современный видеоплеер на **Python + PySide6** с аккуратным тёмным интерфейсом и акцентным красным цветом.

## ✨ Возможности

- 🎨 **Современный UI** — тёмная тема, красный акцент `#E53935`, плавные анимации
- 🌍 **4 языка** — Русский, Українська, Deutsch, 中文 (переключение на лету)
- 💾 **Сохранение настроек** — язык, громкость, папка по умолчанию, библиотека (`QSettings`)
- 📚 **Библиотека видео** — добавление файлов, двойной клик для воспроизведения, автосохранение
- ⚙️ **Страница настроек** — язык интерфейса + папка по умолчанию
- ℹ️ **About-страница** — версия, автор, кликабельная ссылка на репозиторий
- 🎥 **Qt Multimedia + FFmpeg** — встроенный бэкенд, широкий набор форматов (`mp4`, `mkv`, `avi`, `mov`, `webm` и др.)

## 🚀 Установка

### Windows (готовый бинарник)
1. Скачай `ScarlyPlayer-v1.0.0-win64.zip` со страницы [Releases]
2. Распакуй в любую папку
3. Запусти `ScarlyPlayer.exe` — Python не требуется

### Из исходников
```bash
git clone https://github.com/ТВОЙ_НИК/ScarlyPlayer.git
cd ScarlyPlayer
pip install PySide6
python main.py
